# 2026-08-14 — fix(404): честная 404-страница + снятие корневого _middleware

## Корневая причина (аудит утром)
- `src/pages/404.astro` не существовал → билд не эмитил `dist/404.html` → Cloudflare Pages
  включал SPA-fallback: **любой несуществующий путь отдавал HTTP 200 с HTML главной**
  (/key.pem, /wp-login.php, /.env, /api/graphql и бесконечные мутации краулеров
  с наматыванием %25-слоёв — сайт «подтверждал» каждую мутацию кодом 200).
  Петля кодирования в нашем коде НЕ подтверждена: HTML не эхоит путь, middleware-редирект
  кодирование не менял, относительных ссылок нет — слои наматывали сами сканеры.
- `functions/_middleware.js` (корневой UTM-стриппер, июнь 2026) исполнялся на КАЖДОМ
  запросе включая /_astro/*, шрифты, картинки, robots.txt → **~92% всех запросов зоны
  инвокали Pages Function** (101 732 из 110 360 за сутки), cache hit 8.6%.

## Инцидент квоты Functions
- 13.08: 122 486 инвокаций; 14.08: **100 808 / 100 000** — дневная квота free-плана
  Pages Functions исчерпана. Драйверы: middleware-на-всём + краулерный флуд по
  фантомным URL (все через SPA-fallback).
- 2026-08-14 19:51 UTC задеплоен **WAF-блок Yandex-краулера** (зонное правило) —
  остановил основной источник мутированного флуда до кодового фикса.

## Что изменено (ветка fix/honest-404-and-middleware-removal, wt4)
- `src/pages/404.astro` — НОВЫЙ: лёгкая честная 404 в стандартном Layout (шапка/футер/
