## Phase 1 — demand + zero-invention
Ahrefs (US) confirmed all 8 clear >200:
samsung **9,800**, whirlpool 3,600, lg 3,200, maytag 3,000, kenmore 1,800, amana 1,700,
ge 1,400, speed-queen 1,100. (generic "dryer not heating" 8,800 = the umbrella, exists.)

Verified facts (OEM + 2+ where silent):
- **Kenmore = Sears house brand; first 3 model digits = maker** (verified): 110/106=Whirlpool
  (majority), 796/795=LG, 592=Samsung, 417/253=Frigidaire-Electrolux, 363=GE.
- **Whirlpool platform shared** by Whirlpool/Maytag/Amana (+ Kenmore-110): thermal fuse
  (signature no-heat part, blows from restricted vent) + element + thermal cut-off + AF.
- Samsung HE/hE = overheat (clogged vent) + element/thermistor (I-3 reuse). LG = thermal
  fuse #1 + element/thermistor; Flow Sense d80/d90/d95 = airflow (cross-ref lg-d80, NOT
  re-detailed). GE = symptom-diagnosed traditionally; newer 2024+ added HE/E60-E64. Speed
  Queen = commercial-grade/mechanical, few electronics, single hard-part fix.
- Gas vs electric split; **fire framing NFPA (failure-to-clean = #1 dryer-fire factor) +
  USFA (~15,600 fires/yr, lint)** — mandatory on every page.
