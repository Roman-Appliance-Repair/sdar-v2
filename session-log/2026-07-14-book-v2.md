# 2026-07-14 — /book/ redesign (book-v2)

## Что сделано

Полная переделка формы `/book/` — с 13 полей до 4, двухпутевой экран call/form.

**Аудит перед переделкой** (read-only) показал старую форму: одноэкранная, 13 полей (7 обязательных),
submit → `fetch POST /api/contact` (Cloudflare Function → Telegram + Resend). Никаких внешних
виджетов/HCP/iframe/redirect. Трекинг только `booking_submitted` на финальном успехе; клики `tel:`
не форсились в коде (зависели от GTM auto-триггера).

**Новая структура:**
- **Hero, Path A:** крупная красная кнопка `Call Now — {phone}` (самый заметный элемент, mobile
  без скролла). Телефон по branch-детекту: `?city=`/`?branch=` в URL → сохранённый выбор
  (localStorage `sdar_branch`) → дефолт LA `(424) 325-0520`. Дефолт статичен, JS апгрейдит после load.
- **Path B:** разделитель «or book online — 30 seconds» + форма 4 поля: **name\*** · **phone\*** (US-маска
  `(000) 000-0000`) · **ZIP\*** (5 цифр, digits-only) · **what's-wrong** (optional). Honeypot `_hp` сохранён.
- **Убраны:** email, address, area-select, category, appliance-cascade, brand, date, time.
- **ZIP → branch** резолвер в inline-JS: 5-county prefix-map (900-908 LA, 910-912/918 Pasadena,
  913-915 LA/valley, 917/923/924 Rancho, 922/925 Riverside, 926-928 Irvine, 930-931 Thousand Oaks)
  + exact-ZIP оверрайды границ (WeHo 90048/46/69/38/28, Beverly Hills 90209-213, Conejo Valley 913xx
  Thousand Oaks zips); дефолт LA. Slug → payload `city`, эндпоинт по нему выбирает диспетчерский телефон.
- **Submit** без изменений API: `type=booking`, branch из ZIP; inline success/error с филиальным телефоном.
- «How booking works» перенесён **под форму**; BranchNAP-карточки филиалов внизу сохранены.

**Трекинг в коде страницы:**
- `contact_click` `{branch, page:'/book/'}` — делегированный listener на любой `tel:`-клик.
- `form_start` — на первый focus поля формы (once).
- `booking_submitted` `{branch, appliance:<symptom>}` — на успешный submit (как было).

**STEP 3 — эндпоинт:** валидации обязательных полей в `contact.js` **нет** (все поля опциональны:
`p.address || '—'` и т.д.) → укороченный payload проходит без правок. Единственное изменение: добавил
ключ `'riverside': '(951) 577-3877'` в `SDAR_BRANCH_PHONES` (был только устаревший `temecula`) —
чтобы ops Telegram/email показывали верный филиал для Riverside-county ZIP. Send-логика не тронута.

**SEO/schema не тронуты:** 3 JSON-LD блока дословно, pin-идентичность (`8746 Rangely Ave` +
`+1-323-870-4790` в schema). Title 49 симв. Дизайн по design-system (палитра, mobile-first `@media 560px`).
